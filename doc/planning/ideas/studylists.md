# Incorporating Study Lists

I want to be able to incorporate study lists into AlgoPrep.

I have three study lists:
- a LeetCode top 20 generated by Claude Code
- a LeetCode top 20 generated by ChatGPT
- The "Grind 75"

I can create these lists in a format that AlgoPrep can understand, no problem. I can even order them. I can even put some kind of extra information like "Easy" or "20 minutes"


So what do I want AlgoPrep to do?

I want a new optional setting:  Study List File

AlgoPrep will take that study list file, parse it out, and then create a new tab, based on those problems.

15_not-found, Tough, 15 minutes
